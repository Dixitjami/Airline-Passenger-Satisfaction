Airline Passenger Satisfaction Prediction
==========================================

End-to-end machine learning project predicting airline passenger satisfaction.

## Requirements

Install with:
```bash
pip install -r requirements.txt
```

## Usage

Run notebooks in:
```bash
notebooks/
```

Train a model:
```bash
python src/train.py
```

Evaluate:
```bash
python src/evaluate.py
```

Predict:
```bash
python src/predict.py
```

Dashboard:
```bash
streamlit run dashboard/app.py
```
